## Branch 
```markdown
`develop` : default 브랜치, 개발 환경
`main` : 운영 환경
`feat/(이슈 번호)` : 기능 개발, 이슈 번호로 모든 기능을 관리하므로 브랜치에서는 기타 컨벤션 사용하지 않음

- 기능 개발 후 `develop`에 먼저 머지
- `develop` 환경에서 문제 없으면 `main` 머지
```
